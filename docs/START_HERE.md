# StormSight in plain English

You are building a research application for the Nebius x NVIDIA hackathon. Devpost is the entry form. GitHub stores the code. Streamlit displays the application. Nebius supplies the required NVIDIA AI model.

## What already works

The app opens on your computer at http://127.0.0.1:8501/. It shows historical storms, nearby counties, matched FEMA flood insurance payments, a tested model, and a fictional portfolio example. The validation tab shows the model errors. The model is useful for demonstrating research and auditing, but it misses some very large losses.

## What still needs you

The application has not yet made a live NVIDIA model call. Your Nebius account status and credits must be checked. Keep your API key private. The Builder Program application is separate from Token Factory account access.

After the account works, we can connect the exact model shown in your dashboard, test it, publish the app, record the video, and finish Devpost. Creating a Devpost draft does not mean the entry has been submitted. The existing draft can be edited.

## How to show the project

1. Open Storm briefing and select Helene in 2024.
2. Look at the track and county estimates.
3. Open Portfolio to see the fictional example and its corridor value.
4. Open Does it work? to see the model comparison and failures.
5. The Nemotron button becomes usable only when the private service settings are present. It still needs a real successful call before we can claim the integration works.
